# student-platform

واجهة التلميذ لمنصة مدرستي، متصلة بـ Cloudflare Worker.

## الوظائف
- إنشاء ملف التلميذ وتسجيل الدخول بجلسة.
- عرض الأساتذة والأفواج النشطة.
- التسجيل في الأفواج مع حد يومي يفرضه السيرفر حسب توقيت الجزائر.
- عرض الحجوزات والإحصائيات.
- مركز إشعارات يعرض الرسائل الإدارية المنشورة داخل المنصة.
- تحديث الإشعارات الجديدة كل دقيقة أثناء بقاء الصفحة مفتوحة؛ قد يظهر تنبيه محلي عند وجود إذن متصفح والصفحة في الخلفية.

## الإشعارات
هذه إشعارات داخل المنصة وتنبيهات محلية أثناء تشغيل الصفحة فقط. لا تصل بعد إغلاق الموقع أو المتصفح؛ Web Push يحتاج VAPID وService Worker وتخزين اشتراكات وجدولة وإرسال من السيرفر.

## النشر
انشر محتويات المجلد على Cloudflare Pages، وتأكد من أن عنوانه موجود ضمن `ALLOWED_ORIGINS` في Worker.
