# student-platform

واجهة أولية عربية (RTL) لفضاء التلميذ في منصة الدروس الخصوصية.

## التشغيل
افتح `index.html` في المتصفح، أو استخدم إضافة Live Server في VS Code.

## الملفات
- `index.html`: بنية الواجهة.
- `styles.css`: التصميم المتجاوب.
- `app.js`: التحقق الأولي وإظهار الأفواج والاشتراكات والإحصائيات.

## بيانات النسخة التجريبية
- الأستاذ: بومدين، علوم طبيعية، الطور الثانوي.
- الجمعة: الفوج 1 (08:00–10:00)، الفوج 2 (10:00–12:00)، الفوج 3 (14:00–16:00).
- السبت: الفوج 4 (08:00–10:00)، الفوج 5 (10:00–12:00).
- السعر: 300 دج للحصة.
- السعة: غير محدودة.

## تنبيه مهم قبل النشر
هذه واجهة Frontend تجريبية. تحفظ بيانات الملف الشخصي والاشتراكات في `localStorage` على الجهاز فقط. فحص نافذة التسجيل في المتصفح ليس حماية أمنية؛ يجب إعادة التحقق من اليوم والوقت، ومنع التكرار، وحفظ التسجيل في Cloudflare Worker + D1 قبل اعتبار أي اشتراك حقيقياً. لا تستخدم بيانات هذه النسخة لإدارة مدفوعات حقيقية.

## النشر
يمكن نشر هذا المجلد كموقع Static على Cloudflare Pages. سنربطه لاحقاً بـ API الموجود في مستودع `school-server`.
