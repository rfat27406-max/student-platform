# Student platform

واجهة التلميذ لمنصة مدرستي، متصلة بـ Cloudflare Worker.

## الوظائف
- إرسال طلب تسجيل جديد وانتظار مراجعة الإدارة قبل إنشاء حساب أو جلسة.
- متابعة حالة الطلب باستخدام رمز خاص محفوظ محلياً؛ عند الموافقة تُنشأ جلسة التلميذ تلقائياً، وعند الرفض يمكن إرسال طلب جديد.
- عرض الأساتذة والأفواج النشطة والحجوزات والإحصائيات.
- مركز إشعارات واشتراكات Web Push عبر Service Worker عند إعداد مفاتيح VAPID في Worker.

## النشر
انشر محتويات هذا المجلد على Cloudflare Pages، وتأكد من أن عنوان الموقع موجود ضمن `ALLOWED_ORIGINS` في Worker. يجب نشر Worker المتوافق قبل أو بالتزامن مع الواجهة.
