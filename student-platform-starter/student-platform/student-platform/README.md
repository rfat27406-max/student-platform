# student-platform

واجهة التلميذ لمنصة مدرستي، متصلة بـ Cloudflare Worker.

## الوظائف
- إرسال طلب تسجيل جديد وانتظار موافقة الإدارة في صفحة انتظار مستقلة.
- متابعة حالة الطلب تلقائياً؛ عند الموافقة يُنشأ حساب التلميذ وتُفتح الصفحة الرئيسية، وعند الرفض يعود إلى صفحة التسجيل.
- عرض الأفواج فقط، مرتبة حسب الأستاذ والمادة ثم اليوم.
- التسجيل في الأفواج مع حد يومي يفرضه السيرفر حسب توقيت الجزائر.
- عرض الحجوزات والإحصائيات ومركز الإشعارات واشتراكات Web Push.

## النشر
انشر محتويات هذا المجلد مباشرة على Cloudflare Pages. هذه هي النسخة المعتمدة؛ المجلد الفرعي `student-platform/` نسخة مطابقة للتوافق مع بنية المشروع القديمة.
تأكد من أن عنوان الموقع موجود ضمن `ALLOWED_ORIGINS` في Worker.
