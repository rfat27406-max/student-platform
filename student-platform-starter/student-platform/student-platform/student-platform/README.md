# student-platform

واجهة التلميذ لمنصة مدرستي، متصلة بـ Cloudflare Worker.

## الوظائف ومنطق التسجيل
- إدخال الاسم واللقب والعمر (15–18 سنة) لإرسال طلب تسجيل.
- لا يُفتح الحساب قبل موافقة الإدارة؛ تتابع الواجهة حالة الطلب تلقائياً كل 15 ثانية.
- بعد الموافقة يُفعّل الحساب تلقائياً على الجهاز الذي أرسل الطلب.
- عرض الأفواج النشطة فقط، مرتبة حسب الأستاذ والمادة واليوم.
- التسجيل متاح الجمعة والسبت من 07:30 إلى 16:00 بتوقيت الجزائر.
- سعة الأفواج غير محدودة، مع حد يومي قدره 3 حجوزات ناجحة للتلميذ.
- عرض الاشتراكات والحالات والإحصائيات ومركز الإشعارات.
- تذكيرات Web Push اختيارية بعد موافقة المستخدم وإعداد الخادم.

## النشر
انشر محتويات هذا المجلد مباشرة على Cloudflare Pages. هذه هي النسخة المعتمدة؛ المجلد الفرعي `student-platform/` نسخة مطابقة للتوافق مع بنية المشروع القديمة.
تأكد من أن عنوان الموقع موجود ضمن `ALLOWED_ORIGINS` في Worker، وانشر Worker المحدّث أيضاً.
